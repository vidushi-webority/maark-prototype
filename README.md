# MAARK 2.0 — Interactive Prototype

Concept demonstration by **Webority Technologies** for the proposed re-development of
**MAARK (Maintenance Allowance Automated Record Keeping)** to Version 2.0, prepared for
RFP A/60463 (Additional Directorate General of Human Rights, IHQ of MoD, Army).

> ⚠️ **Prototype — demonstration only.** Uses dummy data. This is **not** a live, official,
> or classified Government of India / Ministry of Defence system.

**Live link:** see the repository's GitHub Pages URL.

Three themes: Army Green (`MAARK.html`), Neutral (`MAARK-Neutral.html`), Indigo (`MAARK-Indigo.html`).
100% offline, single-file, zero external dependencies.
