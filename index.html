What the prototype demonstrates

  • Role-based access (User / Admin / Super Admin)
  • SAML 2.0 IAM login + IACA-token 2FA (simulated)
  • Interactive dashboard with live filters & charts
  • 5-section case data-entry wizard
  • Case management: view / edit / approve / transfer
  • Digitally-watermarked, printable reports + CSV export
  • Analytics: district, state & group-of-states
  • Content Management System + V1→V2 migration
  • On-premise, ETAI-compliant AI assistant
  • Comprehensive audit logging
  • AES-256 encryption & RBAC indicators
  • 100% offline — zero external dependencies
How to explore: open any theme → pick a role → enter any 6-digit code as the 2FA token → the interactive dashboard loads. Try clicking the KPI cards, the status filter pills, and the donut chart segments.
