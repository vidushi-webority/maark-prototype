What the prototypes demonstrate

  • Role-based access (User / Admin / Super Admin)
  • SAML 2.0 IAM login + IACA-token 2FA (simulated)
  • Interactive dashboard with live filters & charts
  • Single-page consolidated case data-entry form
  • Case management: view / edit / approve / adjudicate
  • Digitally-watermarked, printable reports + CSV export
  • Interactive analytics — scaled charts, legends & click-to-drill
  • Content Management System + V1→V2 migration
  • On-premise, ETAI-compliant AI assistant (grounded in policies + live data)
  • Comprehensive audit logging
  • AES-256 encryption & RBAC indicators
  • 100% offline — zero external dependencies
How to explore: open a demo → pick a role → enter any 6-digit code as the 2FA token → the interactive dashboard loads. Try the KPI cards, status-filter pills and donut chart, then open the 🤖 AI assistant (bottom-right) and ask e.g. “eligibility rules”, “how many substantiated?”, or “show case 3”.
